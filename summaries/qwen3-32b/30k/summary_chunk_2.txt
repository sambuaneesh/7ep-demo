   - Endpoints: `/books`, `/lend`, `/return`.
   - DB: Books, Borrowers, Loans (Flyway migrations).
   - Tests: Integration tests for loan state management, UI tests for borrowing flow.
3. **Math/Calculation Service**:

   - Stateless logic (Ackermann, Fibonacci).
   - Tests: Performance tests for high inputs.

- **Database per Microservice**: 
  - Replace H2 with PostgreSQL/db per domain, using Flyway per service.
- **Decentralized Deployment**: 
  - Use Docker/Kubernetes to containerize each microservice.
  - Expose APIs via REST/gRPC, managed by an API Gateway.
- **Security Per Service**:
  - Implement ZAP/OWASP scanning as a shared security service or separate for each microservice.

#### **C. CI/CD Pipeline Adaptation**
