#### **5.1 Ackermann Function**  
- **Implements** recursive `A(m, n)` function with two variants:  
  - **Recursive**: `if (m == 0) n + 1; if (n == 0) A(m - 1, 1); else A(m - 1, A(m, n - 1))`.  
  - **Tail Recursive/Iterative**: Optimized using dynamic programming to avoid stack overflow (see `AckermannIterative` class and `calculateIterative()` tests with `BigInteger` for large numbers).  

#### **5.2 Fibonacci Function**  
- **Recursive**: Simple recursive approach with exponential time complexity.  
- **Iterative** (two methods):  
  1. `fibAlgo1()`: Iterates over sequence to compute large numbers.  
  2. `fibAlgo2()`: Alternative iterative algorithm with similar efficiency.  
- **Input Handling Logic**:  
  - Dropdowns for `Borrower` and `Book` selection if total items ≤9.  
  - Autocomplete (JavaScript) for ≥10 items.  
  - Locked inputs if no books or borrowers are registered.  

#### **5.3 Mathematical Operations**  
- **Summation Logic**: `MathServlet` adds two numbers (`item_a + item_b`) and stores results (likely in servlet context or temporary DB).

- **Isolation of Math Logic**: Math functions are stateless and could be exposed as self-contained REST APIs or gRPC services.

- **UI Tests**: Likely redundant in a microservice model where the UI consumes REST APIs (not servlets directly). Conversion to API tests would be necessary.  
- **Database Abstraction**: Current `IPersistenceLayer` supports in-process tests but may require integration with connection pooling (e.g., Hikari) in a microservice.

1. **Refactor Servlets to REST Controllers**

2. **Modularize Mathematical Algorithms**

3. **Externalize Database Management**  
   - Replace `DbServlet` with a Flyway/Docker startup process or a DB management tool.  
   - Use Kubernetes Operators or custom scripts for migration/cleanup.  

4. **Adapt UI Tests to Microservice APIs**  
   - Replace Selenium-based tests with REST clients (e.g., Postman, `requests`).  
   - Test APIs independently of the UI layer.  

5. **Decouple from JSP**  
   - Move results rendering to a separate frontend framework (e.g., Angular, React).  
   - Servlet tests use client requests or JMeter, not internal JSP forwards.
