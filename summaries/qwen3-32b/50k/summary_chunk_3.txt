#### **5. Key Business Logic and Algorithms**

##### **5.1 Password Entropy Checker (RegistrationUtils.java)**
- Measures password strength using Shannon entropy and time-to-crack estimation.
- Rejects passwords with too little or too much entropy.
- Returns a `PasswordResult` with status (`SUCCESS`, `TOO_SHORT`, `BASIC_PASSWORD_CHECKS_FAILED`) and time estimates.

##### **5.2 Book Lending (LendingTests.java)**
- Validates that:
  1. The borrowing user is registered.
  2. The book is available (i.e., no current active loan).
- Tracks lending via lender ID and a set due date (`2018-01-01` in stubs).
- Returns a standardized `LibraryActionResults` or a JSON response with `RESULT_JSP`.

##### **5.3 Ackermann Function (AckermannIterative.java)**
- Two variants: `regular_recursive` and `tail_recursive`.
- The tail-recursive version avoids stack overflow by using iteration over standard recursion.

##### **5.4 Fibonacci (FibonacciIterative.java)**
- Two iterative implementations to compute Fibonacci numbers efficiently.
- Handles arbitrarily large values using `BigInteger`.
