This is a comprehensive educational web application demonstrating full-stack development practices with extensive testing and CI/CD capabilities. The system follows a monolithic architecture with clear domain separation and employs modern software engineering practices.

### 1. Application Server & Runtime
- **Tomcat 9**: Primary application server
- **Java 11**: Runtime environment
- **H2 Database**: Embedded database (file-based and in-memory modes)

### 2. CI/CD Infrastructure
**Jenkins Server (jenkinsbox)**
- Continuous integration/delivery orchestration
- Pipeline management with multi-stage testing
- Integration with Git repositories via post-receive hooks
- Plugin ecosystem (Sidebar-Link, SonarQube Scanner)

**SonarQube (v8.0)**
- Static code analysis
- Code quality gate enforcement
- Technical debt tracking

### 3. Testing Infrastructure
**UI Test Server (uitestbox)**
- Selenium-based UI testing with Chrome/Chromedriver
- OWASP ZAP security scanning proxy (port 9888)
- KDE Plasma desktop environment for visual testing
- Python 3.7 + Behave for BDD testing

### 4. Web Serving & Monitoring
**H2O Web Server**
- Static file serving for test reports
- Directory listing enabled for /reports path
- Accessible reports: Cucumber, Dependency Check, ZAP security

**JConsole Monitoring**
- JMX monitoring on port 9999
- Tomcat performance metrics
